Política de Privacidade

Postagem Histórias de Yahusha. Última atualização: 20 de novembro de 2026.

Quem usa

A ferramenta é de uso próprio e tem um único usuário: o dono do canal Histórias de Yahusha. Ela roda apenas no computador dele. Não existe servidor nem banco de dados externo, e não são usados cookies.

YouTube

A ferramenta usa os serviços de API do YouTube (YouTube API Services). Ao usá-la, você concorda com os Termos de Serviço do YouTube. O uso dos dados pelo Google segue a Política de Privacidade do Google.

Ela usa a API apenas para enviar vídeos, capas, legendas e informações de vídeo do próprio canal, adicionar esses vídeos a playlists do próprio canal e confirmar o nome do canal autorizado.

TikTok

A ferramenta usa o Login Kit e a Content Posting API do TikTok com as permissões user.info.basic (para confirmar qual conta foi conectada) e video.upload (para enviar os vídeos do canal como rascunho para a própria conta). A publicação final é feita pelo dono, no aplicativo do TikTok. O uso segue os Termos de Serviço do TikTok.

Instagram

A ferramenta usa a API oficial da Meta apenas para publicar Reels na conta profissional do próprio canal.

Dados de outras pessoas

A ferramenta não coleta, lê, armazena ou exibe dados de outros usuários, contas ou canais em nenhuma rede.

Armazenamento e compartilhamento

Os acessos (tokens) ficam salvos somente no computador do dono do canal. Nenhuma informação é vendida, compartilhada ou transferida a terceiros.

Exclusão de dados e revogação do acesso

  • Google/YouTube: página de permissões da conta Google.
  • TikTok: no aplicativo, Configurações e privacidade > Segurança > Apps e serviços.
  • Instagram: Configurações > Apps e sites.
  • Apagar os arquivos de acesso no computador exclui na hora todos os dados guardados pela ferramenta.
