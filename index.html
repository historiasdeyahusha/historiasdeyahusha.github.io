Postagem Histórias de Yahusha

Ferramenta de uso próprio do canal. Ela roda apenas no computador do dono do canal e envia os vídeos do próprio canal para as contas oficiais dele:

  • YouTube: envio e agendamento pela API de Dados do YouTube (YouTube API Services).
  • TikTok: envio como rascunho pela Content Posting API, com login pelo Login Kit do TikTok.
  • Instagram: publicação de Reels pela API oficial da Meta.

A ferramenta não é oferecida ao público e tem um único usuário: o dono do canal. Só são enviados vídeos que ele assistiu e aprovou.
